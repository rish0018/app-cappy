# Cappy Docs

This folder contains the core project documentation for Cappy.

## Documents
- [PROJECT_BIBLE.md](PROJECT_BIBLE.md) — product scope, roadmap, and architecture decisions.
- [VISION.md](VISION.md) — the product vision and guiding questions.
- [DECISIONS.md](DECISIONS.md) — key architectural and product decisions, including deviations from PROJECT_BIBLE.md's roadmap.
- [CHANGELOG.md](CHANGELOG.md) — release and project history notes.
- [CONTRIBUTING.md](CONTRIBUTING.md) — contribution workflow and expectations.
- [GUIDE.md](GUIDE.md) — practical setup/run guide: prerequisites, install, `pnpm` commands for web/mobile, environment variables.
- [PROGRESS.md](PROGRESS.md) — current implementation status of the ASL module and shared packages: what's built, what's left, fixed bugs.
- [PROGRESS_MORSE.md](PROGRESS_MORSE.md) — current implementation status of the Morse Code module, and how it integrates with the ASL module.
