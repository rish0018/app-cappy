# Cappy

A monorepo for the Cappy accessibility-learning platform, organized for web, mobile, and ML training work.

## Repository Structure
- apps/web — React/Vite web app
- apps/mobile — Expo React Native app
- apps/training — ML training pipeline
- packages/ui, core, api, types, shared, config — shared code and tooling
- supabase — database, auth, and edge-function assets
- docs — product, vision, architecture, and contributor documentation
